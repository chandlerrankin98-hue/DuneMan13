# Arrakis Companion

A mobile-first companion for *Dune: Awakening* on PS5. The app is built with React, TypeScript, and Vite, with project-based build checklists, catalog references, and local save and recovery tools.

## Repository status

This public repository currently contains this README only. The application source and catalog have not been published here yet. The local catalog includes substantial community-wiki-derived data and saved public API request records; those files need explicit redistribution approval for this public repository. No part of that data has been added to this repository.

## Current app links

- **Production:** [arrakis-companion.pages.dev](https://arrakis-companion.pages.dev/) serves the previously released version 1.3.0.
- **Preview:** [projects-ui-preview.arrakis-companion.pages.dev](https://projects-ui-preview.arrakis-companion.pages.dev/) is the separate test site. It still serves the previously approved preview build; the latest local changes are not deployed.

Publishing this repository does not change either website.

## Project behavior

Each project keeps its own counts. Expand a build target to see its required parts, then expand a part for its direct recipe ingredients. Recording owned or completed quantities does not automatically spend crafting ingredients. Catalog references are partial; unknown recipes and quantities remain marked unknown or incomplete.

## Privacy and licensing
